# Sheet Music

Interactive guitar tablature player with synchronized audio synthesis.

## Contents

- `guitar-tab-player.html` - The interactive tab player artifact (main file)
- `tabs/` - Text tablature files for each song
  - `daredevil_tab.txt` - Daredevil: Born Again theme
  - `odyssey_tab.txt` - The Odyssey main theme
  - `doctorstrange_tab.txt` - Doctor Strange main theme
  - `doctorstrange.mid` - Doctor Strange MIDI
- `data/songs_final.json` - Complete song data (notes, timing, chords, metadata)

## Songs

1. **Daredevil** - E minor, standard tuning, nylon string
2. **Odyssey** - C minor, standard tuning
3. **Doctor Strange** - Bb major/G minor, standard tuning, no capo

## Sync

This repo is the source of truth for the guitar-tab-player artifact.
Changes pushed here are automatically deployed to the live artifact.
